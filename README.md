## Featured projects

### [Compendia](https://github.com/Ereffe/compendia-frontend)
`Next.js 16` `TypeScript` `GraphQL`

A platform for publishing and discussing educational and scientific articles.

- Markdown editor with KaTeX math, images, autosaved drafts and three difficulty levels
- DOI references, an interactive **citation graph** (Cytoscape + Crossref) and APA/BibTeX export
- PDF → article import with live job progress
- Threaded comments, voting and full-text search
- Bilingual UI (Polish / English), talks to a Spring Boot backend over GraphQL

### [Trybik Mobile](https://github.com/TrybikDevelopers/Trybik-frontend-mobile)
`React Native` `TypeScript` `Zustand` `GitHub Actions`

Timetable, exam calendar and ECTS calculator for Mechanical Engineering students at the Cracow University of Technology.

- **Frontend mobile team lead**: took the app from the first screen to a signed release build
- Filterable timetable with week parity, exam calendar, offline caching and PostHog analytics
- CI/CD with GitHub Actions
